NavegaSeguro

Plataforma educativa sobre segurança na internet

=============================================================

1. Sobre o projeto

O NavegaSeguro é um projeto desenvolvido no curso Técnico em Desenvolvimento de Sistemas do Senac. Seu objetivo é conscientizar os usuários sobre a importância da segurança digital por meio de perguntas e respostas

A plataforma permite que os jogadores testem seus conhecimentos sobre segurança na internet, acumulem pontos e acompanhem sua posição no ranking

=============================================================

2. Objetivos

2.1 Incentivar o uso seguro da internet.

2.2 Ensinar sobre ameaças digitais.

2.3 Conscientizar sobre a proteção de dados pessoais.

2.4 Testar os conhecimentos dos usuários por meio de um quiz.

=============================================================

3. Funcionalidades

3.1 Jogador

Cadastro com nome, e-mail e senha.

Login de usuário.

Participação no quiz.

Sistema de pontuação.

Consulta ao ranking.

=============================================================

3.2 Administrador

Login administrativo.

Cadastro de perguntas.

Listagem de perguntas.

Atualização de perguntas.

Exclusão de perguntas.

=============================================================

4. Tecnologias utilizadas

4.1 C# – desenvolvimento da aplicação.

4.2 .NET – ambiente de execução.

4.3 Entity Framework Core – comunicação com o banco de dados.

4.4 MySQL – armazenamento das informações.

4.5 MySQL Workbench – gerenciamento do banco de dados.

=============================================================


5. Banco de dados

O projeto utiliza o MySQL para armazenar:

5.1 Usuários e seus dados de acesso.

5.2 Tipos de usuário (Jogador e Admin).

5.3 Perguntas e alternativas do quiz.

5.4 Respostas corretas e explicações.

5.5 Pontuação e ranking dos jogadores.

=============================================================

6. Como executar o projeto

6.1 Instale o .NET SDK.

6.2 Instale e configure o MySQL.

6.3 Crie o banco de dados NavegaSeguro.

6.4 Configure a conexão com o banco no projeto.

6.5 Crie as tabelas necessárias.

6.6 Insira as perguntas e cadastre um administrador.

6.7 Abra o terminal na pasta do projeto.

=============================================================

Execute:

dotnet restore
dotnet run
